<!-- 核心概念 -->
<section style="margin: 40px 20px 35px 20px;">
<h2 style="margin: 0 0 20px 0; font-size: 20px; font-weight: 700; color: #ffffff; padding-bottom: 10px; border-bottom: 2px solid #58a6ff; display: inline-block;">💡 核心概念：提示词到底是什么？</h2>
<p style="margin: 0 0 15px 0; font-size: 15px; color: #c9d1d9; line-height: 1.8;"><strong style="color: #58a6ff;">提示词（Prompt）</strong>就是你跟AI说的话。</p>
<p style="margin: 0 0 20px 0; font-size: 15px; color: #c9d1d9; line-height: 1.8;">但"说话"和"会说话"是两回事。</p>
<div style="margin: 0 0 20px 0; padding: 20px; background: #161b22; border-radius: 12px; text-align: center; border: 1px solid #30363d;">
<p style="margin: 0 0 10px 0; font-size: 14px; color: #8b949e;">想象你给新来的实习生布置任务：</p>
<p style="margin: 0 0 8px 0; font-size: 15px; color: #f85149;"><strong>❌ 差的指令：</strong>"帮我写个方案"</p>
<p style="margin: 0 0 15px 0; font-size: 15px; color: #3fb950;"><strong>✅ 好的指令：</strong>"帮我写一份针对25-35岁职场女性的护肤品牌小红书推广方案，预算5万以内，重点是种草笔记投放，参考竞品XX的打法，输出3个可选方向"</p>
</div>
<p style="margin: 0; padding: 15px; background: linear-gradient(135deg, #1e3a5f 0%, #162d50 100%); border-radius: 10px; font-size: 15px; color: #c9d1d9; text-align: center;">
<strong>AI跟实习生一样，需要清晰的目标、边界、参考标准。</strong><br/><br/>提示词工程，就是<strong>研究如何把"差的指令"变成"好的指令"</strong>的一套方法论。
    </p>
</section>

<!-- 四个技巧 -->
<section style="margin: 40px 20px 35px 20px;">
<h2 style="margin: 0 0 20px 0; font-size: 20px; font-weight: 700; color: #ffffff; padding-bottom: 10px; border-bottom: 2px solid #58a6ff; display: inline-block;">🛠️ 如何上手：4个立竿见影的技巧</h2>
<div style="margin: 15px 0; padding: 20px; background: #161b22; border-radius: 12px; border-left: 4px solid #58a6ff;">
<p style="margin: 0 0 10px 0; font-size: 16px; font-weight: 700; color: #58a6ff;">🎭 技巧1：给身份，定人设</p>
<p style="margin: 0 0 8px 0; font-size: 13px; color: #f85149;"><strong>❌</strong> "帮我写一篇产品介绍"</p>
<p style="margin: 0 0 10px 0; font-size: 13px; color: #3fb950;"><strong>✅</strong> "你是一名有10年经验的科技媒体编辑，擅长用通俗语言解释复杂技术。请帮我写一篇面向普通消费者的智能手表产品介绍，风格参考'差评'公众号"</p>
<p style="margin: 0; padding: 8px; background: #21262d; border-radius: 6px; font-size: 13px; color: #7eb8da;"><strong>为什么有效？</strong>AI训练数据里有各种风格的文本，"科技编辑"这个身份设定，相当于告诉AI去调取哪个知识子集。</p>
</div>
<div style="margin: 15px 0; padding: 20px; background: #161b22; border-radius: 12px; border-left: 4px solid #a371f7;">
<p style="margin: 0 0 10px 0; font-size: 16px; font-weight: 700; color: #a371f7;">📝 技巧2：给示例，立标杆</p>
<p style="margin: 0 0 8px 0; font-size: 13px; color: #f85149;"><strong>❌</strong> "帮我写个小红书文案"</p>
<p style="margin: 0 0 10px 0; font-size: 13px; color: #3fb950;"><strong>✅</strong> "帮我写个小红书文案，风格参考：'姐妹们！这个神仙精华真的绝了！用了一周皮肤亮了两个度...' 请保持这种口语化、感叹号、种草的语气"</p>
<p style="margin: 0; padding: 8px; background: #21262d; border-radius: 6px; font-size: 13px; color: #a371f7;"><strong>为什么有效？</strong>AI是模式匹配机器，给示例比给描述更精准。</p>
</div>
<div style="margin: 15px 0; padding: 20px; background: #161b22; border-radius: 12px; border-left: 4px solid #3fb950;">
<p style="margin: 0 0 10px 0; font-size: 16px; font-weight: 700; color: #3fb950;">📏 技巧3：给约束，划边界</p>
<p style="margin: 0 0 8px 0; font-size: 13px; color: #f85149;"><strong>❌</strong> "帮我总结这篇文章"</p>
<p style="margin: 0 0 10px 0; font-size: 13px; color: #3fb950;"><strong>✅</strong> "帮我总结这篇文章，要求：300字以内、用3个要点呈现、每个要点不超过50字、保留关键数据"</p>
<p style="margin: 0; padding: 8px; background: #21262d; border-radius: 6px; font-size: 13px; color: #3fb950;"><strong>为什么有效？</strong>没有边界，AI容易写得太长、太散、太泛。约束条件就是过滤器。</p>
</div>
<div style="margin: 15px 0; padding: 20px; background: #161b22; border-radius: 12px; border-left: 4px solid #f0883e;">
<p style="margin: 0 0 10px 0; font-size: 16px; font-weight: 700; color: #f0883e;">🔢 技巧4：给步骤，拆流程</p>
<p style="margin: 0 0 8px 0; font-size: 13px; color: #f85149;"><strong>❌</strong> "帮我策划一场活动"</p>
<p style="margin: 0 0 10px 0; font-size: 13px; color: #3fb950;"><strong>✅</strong> "帮我策划一场活动。请分三步：第一步：先列出5个可能的创意主题，每个一句话；第二步：我选一个后，你给出详细执行方案；第三步：我确认后，你生成宣传文案"</p>
<p style="margin: 0; padding: 8px; background: #21262d; border-radius: 6px; font-size: 13px; color: #f0883e;"><strong>为什么有效？</strong>复杂任务拆成多轮对话，每一步都能纠偏，避免跑偏太远。</p>
</div>
</section>
