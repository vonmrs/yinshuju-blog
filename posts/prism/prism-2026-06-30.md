<h2 style="margin: 0 0 20px 0; font-size: 20px; font-weight: 700; color: #ffffff; padding-bottom: 10px; border-bottom: 2px solid #a371f7; display: inline-block;">🤖 AI写作能力边界</h2>
<div style="margin: 0 0 20px 0; padding: 18px; background: #161b22; border-radius: 10px; border-left: 4px solid #3fb950;">
<p style="margin: 0 0 10px 0; font-size: 15px; font-weight: 600; color: #3fb950;">✅ AI擅长的事</p>
<ul style="margin: 0; padding: 0 0 0 20px; font-size: 14px; color: #c9d1d9;">
<li>信息整合与归纳（读10篇文章，总结出一个结论）</li>
<li>多轮改写与润色（把大白话改成正式语气）</li>
<li>结构化输出（按你给的框架填空）</li>
<li>快速生成初稿（给你一个起点，解决空白页恐惧）</li>
</ul>

<!-- 为什么值得学 -->
<section style="margin: 40px 20px 35px 20px;">
<h2 style="margin: 0 0 20px 0; font-size: 20px; font-weight: 700; color: #ffffff; padding-bottom: 10px; border-bottom: 2px solid #a371f7; display: inline-block;">⚡ 为什么AI写作值得专门学</h2>
<p style="margin: 0 0 15px 0; font-size: 15px; color: #c9d1d9; line-height: 1.8;">一篇像样的公众号文章，从选题到成稿，熟练写手要2-4小时，普通人可能要一整天。用好AI，这个时间可以压缩到<strong style="color: #a371f7;">1小时以内</strong>。</p>
<div style="margin: 0 0 20px 0; padding: 20px; background: linear-gradient(135deg, #2d1b4e 0%, #1a1033 100%); border-radius: 12px; text-align: center;">
<p style="margin: 0 0 10px 0; font-size: 14px; color: #b794f6;">💡 但这不是最重要的理由</p>
<p style="margin: 0; font-size: 16px; color: #ffffff; line-height: 1.8;"><strong>AI把"写得差"的门槛拉高了。</strong></p>
<p style="margin: 10px 0 0 0; font-size: 14px; color: #9f8fdf; line-height: 1.7;">当所有人都能用AI写出60分的内容，"信息搬运工"式的写作就不值钱了。真正值钱的是你的选题判断力、独特视角、以及把AI生成的内容打磨成"像是你写的"的能力。</p>
</div>
<p style="margin: 0; padding: 15px; background: #161b22; border-radius: 10px; border-left: 4px solid #f0883e; text-align: center;">
<span style="font-size: 15px; color: #f0883e;"><strong>不会AI写作的人，将来不只是效率低——是在内容赛场上缺了一条腿。</strong></span>
</p>
</section>

<!-- 四步法 -->
<section style="margin: 40px 20px 35px 20px;">
<h2 style="margin: 0 0 20px 0; font-size: 20px; font-weight: 700; color: #ffffff; padding-bottom: 10px; border-bottom: 2px solid #a371f7; display: inline-block;">🛠️ 如何上手：4步搞定一篇公众号文章</h2>
<div style="margin: 15px 0; padding: 20px; background: #161b22; border-radius: 12px; border-left: 4px solid #58a6ff;">
<p style="margin: 0 0 10px 0; font-size: 16px; font-weight: 700; color: #58a6ff;">🚀 第一步：先自己想清楚，不要急着问AI</p>
<p style="margin: 0 0 8px 0; font-size: 14px; color: #c9d1d9;">打开文档，先自己写：</p>
<ul style="margin: 0; padding: 0 0 0 20px; font-size: 14px; color: #c9d1d9;">
<li>这篇文章要解决什么问题？</li>
<li>读者读完后应该有什么感受或行动？</li>
<li>你自己对这个话题的真实看法是什么？</li>
</ul>
<p style="margin: 10px 0 0 0; padding: 8px; background: #21262d; border-radius: 6px; font-size: 13px; color: #58a6ff; text-align: center;"><strong>把这3个问题写下来，再打开AI。</strong>这是很多人跳过的步骤，但恰恰是最关键的。</p>
</div>
<div style="margin: 15px 0; padding: 20px; background: #161b22; border-radius: 12px; border-left: 4px solid #a371f7;">
<p style="margin: 0 0 10px 0; font-size: 16px; font-weight: 700; color: #a371f7;">📝 第二步：让AI帮你搭骨架</p>
<p style="margin: 0 0 10px 0; font-size: 14px; color: #c9d1d9;">输入这段提示词：</p>
<p style="margin: 0; padding: 12px; background: #21262d; border-radius: 8px; font-size: 13px; color: #a371f7; font-style: italic; line-height: 1.7;">"我要写一篇公众号文章，主题是【XX】，目标读者是【XX】，核心观点是【XX】，希望读者读完后【XX】。请帮我列出文章大纲，包含开头hook、3个分论点、结尾升华，字数分配也标出来。"</p>
<p style="margin: 10px 0 0 0; font-size: 13px; color: #8b949e;">AI给你的大纲，你可以不同意、可以改，但至少解决了一个问题：很多人不是不会写文章，是不知道从哪开始写。</p>
</div>
<div style="margin: 15px 0; padding: 20px; background: #161b22; border-radius: 12px; border-left: 4px solid #3fb950;">
<p style="margin: 0 0 10px 0; font-size: 16px; font-weight: 700; color: #3fb950;">📖 第三步：分块填充，不要让AI写完整篇文章</p>
<p style="margin: 0 0 10px 0; font-size: 14px; color: #c9d1d9;">大纲确定后，分段落让AI写：</p>
<p style="margin: 0; padding: 12px; background: #21262d; border-radius: 8px; font-size: 13px; color: #3fb950; font-style: italic; line-height: 1.7;">"请帮我写开头150字，用一个具体场景或故事切入，引发读者对【XX问题】的共鸣，吸引他们继续往下读。"</p>
<p style="margin: 10px 0 0 0; font-size: 13px; color: #8b949e;">一段一段来，每段都加上你自己的判断：这段话是不是你想表达的？语气对不对？案例贴不贴近你的读者？</p>
</div>
<div style="margin: 15px 0; padding: 20px; background: #161b22; border-radius: 12px; border-left: 4px solid #f0883e;">
<p style="margin: 0 0 10px 0; font-size: 16px; font-weight: 700; color: #f0883e;">✍️ 第四步：人工打磨，这是拉开差距的关键</p>
<p style="margin: 0 0 10px 0; font-size: 14px; color: #c9d1d9;"><strong>AI写出来的东西，有个共同特征：四平八稳、没有脾气。</strong></p>
<p style="margin: 0 0 8px 0; font-size: 14px; color: #c9d1d9;">你要做的是：</p>
<ul style="margin: 0; padding: 0 0 0 20px; font-size: 14px; color: #c9d1d9;">
<li>删掉所有"众所周知"、"毋庸置疑"这种废话</li>
<li>把抽象概念替换成你的具体案例或故事</li>
<li>加入你个人的态度和判断</li>
<li>调整节奏，让文章有起伏</li>
</ul>
<p style="margin: 15px 0 0 0; padding: 12px; background: #21262d; border-radius: 8px; font-size: 14px; color: #f0883e; text-align: center;"><strong>好文章是7分靠改，不是7分靠写。</strong></p>
</div>
</section>

<!-- 常见误区 -->
<section style="margin: 40px 20px 35px 20px;">
<h2 style="margin: 0 0 20px 0; font-size: 20px; font-weight: 700; color: #ffffff; padding-bottom: 10px; border-bottom: 2px solid #a371f7; display: inline-block;">⚠️ 常见误区</h2>
<div style="margin: 10px 0; padding: 15px; background: #161b22; border-radius: 10px; border: 1px solid #30363d;">
<p style="margin: 0 0 5px 0; font-size: 14px; font-weight: 600; color: #f85149;">❌ 误区：让AI一次性写完整篇文章</p>
<p style="margin: 0; font-size: 13px; color: #3fb950;"><strong>正确做法：</strong>AI生成初稿，人工深度修改。AI是起点，不是终点。</p>
</div>
<div style="margin: 10px 0; padding: 15px; background: #161b22; border-radius: 10px; border: 1px solid #30363d;">
<p style="margin: 0 0 5px 0; font-size: 14px; font-weight: 600; color: #f85149;">❌ 误区：不给AI明确的结构和要求</p>
<p style="margin: 0; font-size: 13px; color: #3fb950;"><strong>正确做法：</strong>先自己列提纲，或让AI先出大纲，你审定后再让它填充内容。</p>
</div>
<div style="margin: 10px 0; padding: 15px; background: #161b22; border-radius: 10px; border: 1px solid #30363d;">
<p style="margin: 0 0 5px 0; font-size: 14px; font-weight: 600; color: #f85149;">❌ 误区：直接发布AI生成的内容，不做任何修改</p>
<p style="margin: 0; font-size: 13px; color: #3fb950;"><strong>正确做法：</strong>至少读3遍，加一个真实案例，改一个扎心的标题。</p>
</div>
<div style="margin: 10px 0; padding: 15px; background: #161b22; border-radius: 10px; border: 1px solid #30363d;">
<p style="margin: 0 0 5px 0; font-size: 14px; font-weight: 600; color: #f85149;">❌ 误区：完全依赖AI选题</p>
<p style="margin: 0; font-size: 13px; color: #3fb950;"><strong>正确做法：</strong>AI可以帮你扩展选题角度，但真正的爆款选题来自你对读者的理解和对时事的敏感。</p>
</div>
</section>
