<!-- 核心概念 -->
<section style="margin: 36px 20px 0 20px;">
<h2 style="margin: 0 0 16px 0; color: #ffffff; font-size: 18px; font-weight: 700; padding-left: 14px; border-left: 3px solid #a371f7; line-height: 1.4;">💡 核心概念：从"写代码"到"描述代码"</h2>
<p style="margin: 0 0 14px 0; color: #c9d1d9; font-size: 15px; line-height: 1.8;">AI编程的核心逻辑是<strong style="color: #58a6ff; font-weight: 600;">自然语言到代码的翻译</strong>。你告诉AI你想要什么，它帮你翻译成机器能懂的语言。这个转变意味着编程的本质从<strong style="color: #b794f6; font-weight: 600;">"how"（怎么写）</strong>变成了<strong style="color: #b794f6; font-weight: 600;">"what"（写什么）</strong>。</p>
<p style="margin: 0; color: #c9d1d9; font-size: 15px; line-height: 1.8;">好比做菜：过去你是一个厨子，得知道切菜火候调味。现在你是一个点菜的人，告诉厨师你想吃什么就行。AI就是厨师，用数百万条代码训练出来的"味觉"帮你实现。</p>
</section>

<p style="margin: 0 0 14px 0; padding-top: 12px; border-top: 1px solid #21262d; color: #c9d1d9; font-size: 15px; line-height: 1.8;"><strong style="color: #3fb950;">第一层 · 代码补全</strong><br/><span style="color: #8b949e; font-size: 14px;">Copilot / Codeium —— 像输入法的联想功能，你写一半，AI帮你补完。适合有基础的人加速编码。</span></p>
<p style="margin: 0 0 14px 0; padding-top: 12px; border-top: 1px solid #21262d; color: #c9d1d9; font-size: 15px; line-height: 1.8;"><strong style="color: #58a6ff;">第二层 · 对话式生成</strong><br/><span style="color: #8b949e; font-size: 14px;">ChatGPT / Claude —— 你说"帮我写个Python脚本批量重命名文件"，AI直接给你完整代码。</span></p>

<section style="margin: 24px 20px 0 20px; color: #ffffff; font-size: 15px; line-height: 1.8;">
<p style="margin: 0;"><strong>第四步：学读代码胜过写代码</strong></p>
</section>
<section style="margin: 12px 20px 0 20px; color: #c9d1d9; font-size: 15px; line-height: 1.8;">
<p style="margin: 0;">一个反直觉的建议：<strong style="color: #f0883e; font-weight: 600;">初学者花更多精力学"读代码"而非"写代码"。</strong> AI生成代码后，别直接关掉。逐行读一遍，不理解的地方问AI。读得多了，你会发现代码有固定的模式——判断循环、函数定义、错误处理。当你读到能看出AI生成的代码哪里写得不好的时候，你就入门了。</p>
</section>
<!-- 常见误区 -->
<section style="margin: 36px 20px 0 20px;">
<h2 style="margin: 0 0 16px 0; color: #ffffff; font-size: 18px; font-weight: 700; padding-left: 14px; border-left: 3px solid #a371f7; line-height: 1.4;">⚠️ 常见误区</h2>
</section>
<!-- 误区1 -->
<section style="margin: 12px 20px 0 20px; padding: 16px 20px; background: rgba(248, 81, 73, 0.08); border: 1px solid rgba(248, 81, 73, 0.2); border-radius: 8px;">
<p style="margin: 0 0 4px 0; color: #f85149; font-weight: 700; font-size: 13px; letter-spacing: 1px;">❌ 误区</p>
<p style="margin: 0 0 4px 0; color: #c9d1d9; font-size: 14px; font-weight: 600;">AI生成的代码肯定没问题</p>
<p style="margin: 0; color: #c9d1d9; font-size: 14px;">一句话：AI写代码能跑，但不代表没bug。变量名拼错、逻辑遗漏、依赖版本不对——这些是家常便饭。</p>
</section>
<section style="margin: 12px 20px 0 20px; padding: 16px 20px; background: rgba(63, 185, 80, 0.08); border: 1px solid rgba(63, 185, 80, 0.2); border-radius: 8px;">
<p style="margin: 0 0 4px 0; color: #3fb950; font-weight: 700; font-size: 13px; letter-spacing: 1px;">✅ 正确做法</p>
<p style="margin: 0 0 4px 0; color: #c9d1d9; font-size: 14px; font-weight: 600;">永远假设AI的代码需要你验证</p>
<p style="margin: 0; color: #c9d1d9; font-size: 14px;">裸跑AI代码到生产环境 ≈ 没试过菜就端给客人。每次生成后先review、再测试。</p>
</section>
<!-- 误区2 -->
<section style="margin: 12px 20px 0 20px; padding: 16px 20px; background: rgba(248, 81, 73, 0.08); border: 1px solid rgba(248, 81, 73, 0.2); border-radius: 8px;">
<p style="margin: 0 0 4px 0; color: #f85149; font-weight: 700; font-size: 13px; letter-spacing: 1px;">❌ 误区</p>
<p style="margin: 0 0 4px 0; color: #c9d1d9; font-size: 14px; font-weight: 600;">AI会取代程序员，不用学了</p>
<p style="margin: 0; color: #c9d1d9; font-size: 14px;">AI提升了产出效率，但没有消除对"编程思维"的需求。你依然需要知道什么是循环、API、数据结构。</p>
</section>
<section style="margin: 12px 20px 0 20px; padding: 16px 20px; background: rgba(63, 185, 80, 0.08); border: 1px solid rgba(63, 185, 80, 0.2); border-radius: 8px;">
<p style="margin: 0 0 4px 0; color: #3fb950; font-weight: 700; font-size: 13px; letter-spacing: 1px;">✅ 正确做法</p>
<p style="margin: 0 0 4px 0; color: #c9d1d9; font-size: 14px; font-weight: 600;">不会写代码的人能跑通demo，懂编程的人能搭建可靠产品</p>
<p style="margin: 0; color: #c9d1d9; font-size: 14px;">两者的差距：一个是玩玩具，一个是做工具。AI拉平了门槛，但没填平深坑。</p>
</section>
<!-- 误区3 -->
<section style="margin: 12px 20px 0 20px; padding: 16px 20px; background: rgba(248, 81, 73, 0.08); border: 1px solid rgba(248, 81, 73, 0.2); border-radius: 8px;">
<p style="margin: 0 0 4px 0; color: #f85149; font-weight: 700; font-size: 13px; letter-spacing: 1px;">❌ 误区</p>
<p style="margin: 0 0 4px 0; color: #c9d1d9; font-size: 14px; font-weight: 600;">总让AI从头写，不迭代</p>
<p style="margin: 0; color: #c9d1d9; font-size: 14px;">一次搞定所有要求的prompt，往往得到的是错误百出的大杂烩。</p>
</section>
<section style="margin: 12px 20px 0 20px; padding: 16px 20px; background: rgba(63, 185, 80, 0.08); border: 1px solid rgba(63, 185, 80, 0.2); border-radius: 8px;">
<p style="margin: 0 0 4px 0; color: #3fb950; font-weight: 700; font-size: 13px; letter-spacing: 1px;">✅ 正确做法</p>
<p style="margin: 0 0 4px 0; color: #c9d1d9; font-size: 14px; font-weight: 600;">逐步迭代：先骨架→跑通→改功能→优化性能</p>
<p style="margin: 0; color: #c9d1d9; font-size: 14px;">高手用AI编程的方式：一小步一小步往前走，每一步都确认结果再提新要求。</p>
</section>
