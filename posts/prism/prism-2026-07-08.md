<!-- 标题区 -->
<section style="padding: 36px 24px 28px;">
<p style="font-size: 12px; color: #a371f7; margin: 0 0 14px; letter-spacing: 1px; text-transform: uppercase;"># 第二期 · 第1天 · ComfyUI概览</p>
<h1 style="font-size: 26px; font-weight: 700; color: #ffffff; line-height: 1.3; margin: 0 0 14px;">把生图从「黑盒」变成「流水线」</h1>
<p style="font-size: 14px; color: #8b949e; margin: 0; line-height: 1.5;">它不是又一个画图软件，而是一块让你亲手搭出图像流水线的电路板。</p>
</section>
</section>
<!-- 命令行正文 -->
<section style="padding: 0 0 32px; background: #0d1117;">
<!-- 概念解释 -->
<section style="background: #161b22; border: 1px solid #30363d; border-radius: 8px; padding: 20px; margin: 0 16px 16px;">
<p style="font-size: 11px; color: #58a6ff; font-weight: 600; margin: 0 0 10px; letter-spacing: 2px; text-transform: uppercase;">// 概念</p>
<p style="font-size: 15px; color: #c9d1d9; line-height: 1.8; margin: 0;">先别被名字吓到。说人话：它是一个<span style="color: #58a6ff;">用方块和连线来生图的工具</span>。打个比方——如果说 Midjourney 是「一键美颜相机」，你按一下快门它就给你一张；那它更像「专业调色台 + 自己接线的电路板」，底层跑的是 Stable Diffusion 这类图像模型。</p>
<p style="font-size: 15px; color: #c9d1d9; line-height: 1.8; margin: 12px 0 0;">核心区别就一句：在别处，一张图是「结果」；在这里，一张图是「配方」。每一步都看得见、改得了、存得下。我第一次打开它，满屏方块和线，差点以为误进了程序员的世界——但跑通第一个流程后我悟了：它比对话框更讲理。</p>
<p style="font-size: 15px; color: #c9d1d9; line-height: 1.8; margin: 12px 0 0;">为什么值得学？三点：<span style="color: #3fb950;">可控</span>（换模型、换采样器、加 ControlNet，节点一拖就改）；<span style="color: #3fb950;">可复用</span>（工作流存成 JSON，团队直接传配方）；<span style="color: #3fb950;">省显存</span>（我那台 8G 显卡的笔记本，就是靠它跑通了 SD1.5，很多「一键工具」根本开不起来）。</p>
</section>
<!-- 命令示例 -->
<section style="background: #0d1117; margin: 0 16px 16px; border-left: 3px solid #3fb950; padding: 16px 20px;">
<p style="font-size: 11px; color: #3fb950; font-weight: 600; margin: 0 0 10px; letter-spacing: 1px;">// 命令</p>
<p style="font-size: 14px; color: #c9d1d9; line-height: 1.6; margin: 0; font-family: 'Fira Code', 'Courier New', monospace;"><span style="color: #3fb950;">$</span> 打开 ComfyUI → Load（加载工作流JSON）→ 点 Queue Prompt</p>
</section>
<!-- 输出示例 -->
<section style="background: #161b22; border: 1px solid #30363d; border-radius: 8px; padding: 16px 20px; margin: 0 16px 16px;">
<p style="font-size: 11px; color: #8b949e; font-weight: 600; margin: 0 0 10px; letter-spacing: 1px;">// 输出</p>
<p style="font-size: 13px; color: #c9d1d9; line-height: 1.7; margin: 0; font-family: monospace;">&gt;&gt; 模型已加载：SD1.5 (fp16)<br/>&gt;&gt; 工作流已解析：7 个节点<br/>&gt;&gt; 队列已提交，采样 step 1/20 ...<br/>&gt;&gt; 出图完成 → 512×512，耗时 3.2s</p>
</section>
<!-- 步骤清单 -->
<section style="padding: 0 16px; margin-bottom: 16px;">
<p style="font-size: 11px; color: #a371f7; font-weight: 600; margin: 0 0 12px; letter-spacing: 2px; text-transform: uppercase;">// 步骤</p>
<p style="font-size: 14px; color: #c9d1d9; line-height: 1.8; margin: 0 0 8px;"><span style="color: #58a6ff;">1.</span> 先跑起来：本地用整合包解压即开；我自己的路径是<span style="color: #58a6ff;">先上云</span>镜像，省去装环境的折磨，新人建议先上云。</p>
<p style="font-size: 14px; color: #c9d1d9; line-height: 1.8; margin: 0 0 8px;"><span style="color: #58a6ff;">2.</span> 跑通第一个工作流：加载文生图最简 JSON，点 Queue Prompt 看图。<span style="color: #8b949e;">先别管节点什么意思，先看到图。</span></p>
<p style="font-size: 14px; color: #c9d1d9; line-height: 1.8; margin: 0;"><span style="color: #58a6ff;">3.</span> 开始小改：换提示词、换模型、加一个「高清放大」节点。每次只改一处，跑一次建立直觉。</p>
</section>
<!-- 注意事项 -->
<section style="background: rgba(240,136,62,0.1); border: 1px solid rgba(240,136,62,0.25); border-radius: 8px; padding: 16px 20px; margin: 0 16px 16px;">
<p style="font-size: 12px; color: #f0883e; font-weight: 600; margin: 0 0 8px;">⚠️ 注意</p>
<p style="font-size: 14px; color: #c9d1d9; line-height: 1.7; margin: 0;">误区一：以为必须会编程——不用写一行代码，拖节点就行。误区二：节点越多越专业——反了，能用 5 个解决的别套 20 个。误区三：显卡差跑不了——选对模型 + 精简流，8G 也能玩。我踩过的真坑：某个节点插件更新后和新版主程序冲突，整条流打不开；解法很土，用整合包固定版本，别盲目追新。</p>
</section>
