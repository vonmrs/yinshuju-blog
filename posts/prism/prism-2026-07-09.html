# ComfyUI · 第2天 · 文生图

文生图工作流拆解：把最简流程的6个节点讲透

别再对着对话框许愿了。一张图，不过是 6 个方块用线串起来的一次"流动"。

// 概念

昨天说了：在 ComfyUI 里，一张图是「配方」不是「结果」。这个最简配方说人话就是一条从左到右的流水线，一共 6 个节点：加载模型 → 写提示词 → 定画布 → 采样 → 解码 → 保存。每个节点只干一件事，给上游"喂料"、向下游"吐料"。跑通一次，就是这批料从左到右流一遍，最后屏幕上蹦出一张图。

我自己的路径：先别管原理，把官方那个"文生图最简流程"的 JSON 打开，点一下 Queue Prompt，看图出来——那一刻你才算"进屋"。然后才是把每个方块认清楚。

// 最简链路（节点顺序）

$ CheckpointLoader → CLIP Encode(±) → EmptyLatent → KSampler → VAEDecode → SaveImage

// 输出

✓ 6 个节点就绪，连线无报错
✓ Queue Prompt 已触发
✓ 图已保存 → output/ComfyUI_0001.png

// 节点拆解（核心）

① 加载模型 CheckpointLoaderSimple
整条流的"地基"。加载 .safetensors/.ckpt 底模，一次性吐出三路：MODEL（大脑）、CLIP（读提示词）、VAE（解码）。像咖啡机主机，后面全从它身上接电。

② 提示词编码 CLIP Text Encode
把你的句子变成模型懂的"条件"。要放两个：正向（画什么）+ 反向（别画什么，如糊、畸形、水印）。

③ 空画布 Empty Latent Image
决定图多大、出几张（宽/高/batch）。SD1.5 原生只认 512 左右，硬设 1024 会变形——我那台 8G 破本最早不懂这个，出的脸全是扁的。

④ 采样器 KSampler（心脏）
把四个输入一步步"画"成潜空间图。关键参数：seed（固定可复现）、steps（20–30）、cfg（8 左右甜区）、sampler+scheduler（新人先 euler+normal）。

⑤ 解码 VAEDecode
把"人眼看不懂的潜空间图"翻译成真正能看的像素图。接 KSampler 的 LATENT + 加载器给的 VAE。

⑥ 保存 SaveImage
存到本地 output 文件夹。没它，图只在内存里闪一下就没了。

// 步骤（上手三连）

1. 开：菜单 Load 一个现成「文生图最简流」JSON，先看见图，别从零画。

2. 改：正向提示词换成你自己的，反向填「糊、畸形、水印」，点 Queue Prompt。

3. 连：从空白画布拖这 6 个节点，照顺序连一遍。连错线软件会标红——它比你讲理。

⚠️ 我踩过的坑

第一次跑只接了正向、忘了接反向到 KSampler，出图一堆瑕疵，我还以为模型不行——其实是反向那条线没接。第二个坑：版本不兼容，某节点插件更新后和主程序打架，整条流直接打不开。我的土办法：用整合包固定版本，别盲目追新。

// 常见误区

误区 正确做法
「6 个节点太多记不住」 记"地基→条件→画布→心脏→翻译→存盘"这条线，顺序比名字重要
「反向提示词无所谓」 忘了接反向，图全是瑕疵；它是"排雷线"
「尺寸越大越清晰」 SD1.5 设太大反而变形；清晰度靠放大节点，不是硬撑尺寸
「采样器要选最牛的」 先 euler+normal 跑通；算法是锦上添花，不是雪中送炭

// 进阶方向

今天你只要搞懂一件事：文生图 = 一个从左到右的节点链路，KSampler 是心脏，加载模型是地基。

明天我们钻进 KSampler 和提示词内部——steps、cfg、sampler 到底怎么调，把"能出图"变成"出得准"。
