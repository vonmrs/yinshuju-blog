## 第2天：文生图工作流拆解——把最简流程的6个节点讲透

> **钩子：别再对着对话框许愿了。一张图，不过是 6 个方块用线串起来的一次"流动"。今天我把最简文生图流程的节点一个个拆给你看，看完你会发现：它比你想的简单，也比你想的讲理。**

---

### 一、先建立一个画面：文生图 = 一条流水线

昨天我们说了，ComfyUI 里一张图是「配方」不是「结果」。

那这个最简配方长啥样？说人话：**它是一条从左到右的流水线**，一共 6 个节点：

```
加载模型 → 写提示词(正向/反向) → 定画布 → 采样 → 解码 → 保存
```

<!-- 配图提示词：从左到右6个节点连成一条发光流水线的极简示意图，节点用圆角方块，连线为流动光线，科技蓝白风 -->

每个节点只干一件事。你给上游的节点"喂料"，它"加工"完吐给下游。跑通一次，就是这批料从左流到右，最后在屏幕上蹦出一张图。

我自己的路径是：先别管原理，把官方那个"文生图最简流程"的 JSON 打开，点一下 Queue Prompt，看图出来——那一刻你才算"进屋"了。然后才是今天这堂课：把每个方块认清楚。

---

### 二、6 个节点，逐个拆（这是今天的核心）

**① 加载模型（CheckpointLoaderSimple）**
这是整条流的"地基"。它加载一个 `.safetensors` 或 `.ckpt` 底模文件，一次性吐出三路东西：**MODEL（大脑）、CLIP（读提示词的能力）、VAE（把图解码出来的能力）**。
类比：它像一台咖啡机的"主机"，后面所有环节都从它身上接电。

**② 提示词编码（CLIP Text Encode）**
把你的中文/英文提示词，变成模型能懂的"条件"。这里要放**两个**：正向（告诉它画什么）和反向（告诉它别画什么，比如「糊、多手指、水印」）。
我踩过最蠢的坑：第一次跑，只接了正向、忘了接反向到 KSampler。出图一堆乱七八糟的瑕疵，我还以为模型不行——其实是反向提示词那条线没接。

**③ 空画布（Empty Latent Image）**
决定图多大、出几张。参数是宽、高、batch_size（一次出几张）。
**重点坑**：SD1.5 底模原生只认 512×512 左右，你硬设 1024×1024，图会被"拉伸"变形。我那台 8G 显卡的破本子，最早就是不懂这个，出的图脸都是扁的。换成 512×768 这类接近原生的尺寸，立马正常。

**④ 采样器（KSampler）—— 整条流的心脏**
它把"模型 + 正向条件 + 反向条件 + 空画布"四个输入，一步步"画"成一张潜空间图。关键参数就四个：
- **seed**：随机种子。固定它 = 同一句话能复现同一张图；想换花样就随机化。
- **steps**：步数。一般 20–30。
- **cfg**：提示词服从度。太高图死板，太低模型乱来，8 左右是甜区。
- **sampler_name / scheduler**：采样算法。新人先用 `euler` + `normal` 跑通再说，别纠结。

**⑤ 解码（VAEDecode）**
把上一步那张"人眼看不懂的潜空间图"，用 VAE 翻译成真正能看的像素图。它接 KSampler 的 LATENT，再接加载器给的 VAE。

**⑥ 保存（SaveImage）**
把图存到本地 output 文件夹。没它，图只在内存里闪一下就没了。

### 三、怎么上手搭一遍（3 步，别贪多）

1. **开**：打开 ComfyUI，菜单 Load 一个现成「文生图最简流」JSON（官方示例里就有）。别自己从零画，先看见图。
2. **改**：把正向提示词换成你自己的句子，反向提示词填「糊、畸形、水印」。点 Queue Prompt。
3. **连（进阶）**：试着自己从空白画布拖这 6 个节点，照上面的顺序连一遍。连错线软件会直接标红——它比你讲理。

我现在的习惯：把这个最简流存成 `my-base.json`，每天换提示词批量出图。它就像一个"干净的底盘"，后面接 LoRA、接高清放大，都是往这个底盘上叠。

---

### 四、常见误区（对比看）

| 误区 | 正确做法 |
|------|---------|
| 「6 个节点太多，记不住」 | 记住"地基→条件→画布→心脏→翻译→存盘"这条线，顺序比名字重要 |
| 「反向提示词无所谓」 | 忘了接反向，图全是瑕疵；它是"排雷线" |
| 「尺寸越大越清晰」 | SD1.5 设太大反而变形；清晰度靠第6天的放大节点，不是硬撑尺寸 |
| 「采样器要选最牛的」 | 先 `euler+normal` 跑通；算法是锦上添花，不是雪中送炭 |
| 「seed 每次手动换」 | 想复现就固定 seed；想探索就点随机化，别死磕手动输入 |

### 五、进阶方向

今天你只要搞懂一件事：**文生图 = 一个从左到右的节点链路，KSampler 是心脏，加载模型是地基。**

明天我们钻进 KSampler 和提示词内部——steps、cfg、sampler 到底怎么调，才能让图更"懂你"。那是把"能出图"变成"出得准"的关键一步。

踩坑预告：版本不兼容。某个节点插件更新后和新版主程序打架，整条流直接打不开。我的土办法——用整合包固定版本，别盲目追新。这条坑我替你踩过了。
