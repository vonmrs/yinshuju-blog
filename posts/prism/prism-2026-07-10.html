# ComfyUI · 第3天 · 提示词与采样器

提示词与采样器：把出图从"碰运气"变成"调旋钮"

同样一句话，有人出大片有人出车祸现场。差距不在模型，在你会不会写提示词、调采样器。

// 概念

正向提示词，说人话就是给模型的"画图说明书"。它认的不是一句人话，而是一堆带权重的标签。昨天你跑通了 6 节点流，可能已经发现：同样一条流，换个提示词，出来的东西天差地别。

我踩过最典型的坑：刚上手时把提示词当作文写——"一个穿红裙子的女孩站在海边，阳光很好，希望温暖一点"。结果？红裙子变橘色、海边像泳池、温暖感全无。后来换成"标签堆叠法"才开窍：模型听不懂形容词，只听得懂名词 + 风格词。

// 提示词四段结构（标签化）

$ 主体: 1girl, red dress, long hair
$ 环境: seaside, golden hour, waves
$ 风格: cinematic lighting, film grain
$ 画质: highly detailed, 8k, sharp focus

// 输出

✓ 标签化重写完成，模型已识别 12 个 tag
✓ Queue Prompt 已触发
✓ 出图方向对齐：红裙 / 海边 / 电影光 ✓

// 提示词与采样器拆解（核心）

① 提示词结构
按"主体 + 环境 + 风格 + 画质"四段堆标签，别写成作文。把"希望温暖一点"翻译成模型认得的 golden hour + cinematic lighting，图立刻就对了。

② 权重语法
用括号和冒号给词加权重——(red dress:1.3) 拉高、(wave:0.8) 弱化处理。我自己的路径：先不加权重跑一遍，看哪块跑偏，再单独给它加权。别一上来全加，图会"用力过猛"比例崩。

③ 反向提示词（排雷线）
我的固定黑名单：blurry, lowres, bad anatomy, extra fingers, watermark, text。这条线接对了，能挡掉八成"翻车图"。

④ 采样器 KSampler 四旋钮
steps（20–30 甜区，再多纯费电）、cfg（7–8 甜区，过高图发硬）、sampler+scheduler（新人先 euler+normal，想细用 dpmpp_2m+karras）、seed（锁死可复现，随机可探索）。

我实测过：SD1.5 跑到 25 步基本定型，加到 50 步肉眼几乎无差、时间却翻倍。还有次把 cfg 拉到 15 想"更听话"，人脸像塑料、背景糊成一团——7–8 才是甜区。

// 步骤（上手三连）

1. 写对：提示词按"主体+环境+风格+画质"四段写，别写成作文。

2. 调参：KSampler 先设 steps=25, cfg=7, euler+normal，出一张看效果。

3. 微调：哪块不对，单独加权重或动对应旋钮。每次只动一个变量，跑一次看变化。

⚠️ 我踩过的坑

第一个坑：一度把 cfg 拉到 15 想"让它更听话"，结果人脸像塑料、背景糊成一团——cfg 7-8 才是甜区。第二个坑：版本不兼容，某节点插件一更新和新版主程序打架，整条流直接打不开。我的土办法：用整合包固定版本，别盲目追新。

// 常见误区

误区 正确做法
「提示词写得越长越好」 标签化、结构化；太长反而稀释重点，模型抓不住主次
「中文提示词直接丢进去」 翻译成英文标签词效果更稳；中文常需模型本身支持
「cfg 拉满模型更听话」 7–8 甜区；过高图死板、颜色发硬
「steps 越多越清晰」 20–30 够用；过甜区纯耗时间
「每次都手动换 seed」 先随机挑满意的锁死 seed，再微调，效率最高

// 进阶方向

今天你只要搞懂一件事：提示词定方向，采样器定命；单变量微调，比盲目重跑强十倍。

明天我们讲「模型与 LoRA」——同一个流，换个底模、加个 LoRA，风格瞬间切换。那是把"能出图"变成"出得有辨识度"的关键一步。

// 动手之前，先聊聊

你现在写提示词，是"写成一句作文"还是"已经开始堆标签词"？你最常被哪个参数坑——是 cfg 拉太高图发硬，还是 seed 没锁死每次都换一张脸？评论区报一下，明天讲 LoRA 时我顺带教你怎么用 seed 复现满意图。
