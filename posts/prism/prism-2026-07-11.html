# ComfyUI · Day 4 · 参数调优

步数调高≠更清晰

KSampler 四个框，调错了图就糊、崩、慢——今天专治这三种病。

// 概念

把采样器想成"画家的笔法"：采样器决定怎么画，步数决定落几笔，CFG决定多听话。笔法不对，再描也救不回那张脸；画到第七笔已成型，后面再描就是来回涂改。

// 命令

$ KSampler: sampler=DPM++ 2M Karras, scheduler=Karras, steps=28, cfg=7

// 输出

✔ image saved — 28 steps, 3.2s on 4070Ti
✔ 细节干净，无塑料感，无灰雾

// 步骤

1. SD1.5 底模：Euler a + steps 20-30 + CFG 7，新手最稳组合，不出错。

2. SDXL 底模：DPM++ 2M Karras + steps 25-35 + CFG 6-7，最省时省卡的搭配。

3. scheduler 别乱动：Normal / Karras 二选一，Karras 收尾更干净。

4. 显卡吃紧：步数砍到 20，换更快的采样器（如 UniPC），出图速度翻倍。

⚠️ 注意

误区：步数越多越清晰。正确做法：SDXL 在 20-35 步基本到顶，再往上收益递减甚至回退。

误区：CFG 越高越符合提示词。正确做法：超过 10 画面开始僵硬过饱和，7 左右是甜点区。

误区：采样器随便选。正确做法：写实人像认准 DPM++，动漫插画感用 Euler a。
