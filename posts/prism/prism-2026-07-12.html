ComfyUI生图系列 · Day 5

ControlNet 控制网：让AI乖乖听你话

没有ControlNet，你的AI生图就是在撞大运；有了ControlNet，才是真正的设计。

// 核心概念

先说个我踩过的坑。

刚开始用Stable Diffusion的时候，我跟所有人一样：输入提示词，点生成，等着看命运给你什么惊喜。有时候抽到一张神图，更多时候——尤其是你要精确控制姿态、构图、线稿的时候——就是一堆四不像。手指多了两根、建筑歪了、人物站姿完全不对。

直到我认真研究了ControlNet，才意识到一个问题：我们一直把AI当成"猜你想画"的机器，但实际上它可以做得更精准——前提是你给它足够的"参照物"。

通俗说，ControlNet就是给AI加了一个额外的"约束条件输入口"。

类比一下：ControlNet就像是摄影师用的构图辅助线。普通人拍照全凭感觉，专业摄影师会用网格线、三分法、引导线——ControlNet就是AI画图的"构图辅助线"，让你从"随机生成"升级到"精准控制"。

// ControlNet能读懂哪些控制信号

🎯 Canny 边缘检测

按线稿生成，保留原始轮廓 — 就像填色本，AI负责上色

🗺️ Depth 深度图

控制空间结构和纵深关系 — 适合建筑、场景、3D感强的图

🧍 OpenPose 骨骼

控制人物姿态和手势 — 画手神器，解决手指乱飞的问题

🏗️ MLSD 线段检测

提取建筑/直线的几何结构 — 适合建筑渲染、室内设计

// 为什么重要

1. 解决AI"手残"问题 — AI画手是经典翻车现场。ControlNet通过骨骼控制（OpenPose），可以精确指定手的姿态和位置。我实测过：没用ControlNet画手，出错率大概70%；加上OpenPose控制，出错率降到20%左右。

2. 实现风格一致性 — 做品牌视觉时，你希望AI生成的角色在多张图里保持同一个pose和构图？用ControlNet锁定参考图骨架，就能保证多张图的人物姿态一致。

3. 线稿上色和建筑渲染 — 设计师朋友用得最多的场景：扫描手绘线稿，用ControlNet生成上色图。我在一次给客户提案时就这么用过——客户手绘了一张草图，我10分钟出了三套渲染方案，当场拿下。

4. 精准构图控制 — 有时候你脑子里有一张完美构图的画面，但文字描述出来完全走样。用一张参考图提取深度图或边缘线，AI就在这个"画框"里生成，构图不会跑偏。

// 操作步骤

01安装ControlNet节点：打开ComfyUI Manager → Install Custom Nodes → 搜索 ControlNet → 安装后重启ComfyUI

02下载ControlNet模型：从Hugging Face下载对应模型（如 control_v11p_sd15_canny），放入 ComfyUI/models/controlnet/ 目录（我踩过坑，一定确认是这个路径，不是根目录）

03搭建工作流：Load Image（参考图）→ ControlNet Preprocessor（预处理）→ CLIP Text Encode（提示词）→ KSampler（采样生成）

04调试Strength强度：强度越高AI越听话（但可能牺牲自然度），我一般从 0.7-0.85 开始调，效果比较均衡

// 常见误区

❌ 误区

✅ 正确做法

ControlNet能100%复刻参考图

它是"约束"不是"复制"，结果会有AI的自由发挥

所有模型都支持ControlNet

必须是SD 1.5/SDXL基础模型，SD 2.x需要对应版本

ControlNet越强越好

强度太高会破坏画面自然度，建议0.6-0.9之间调试

ControlNet可以完全替代提示词

两者必须配合使用，ControlNet控制结构，提示词控制风格

// 进阶方向

→ 多ControlNet叠加：同时用2-3个ControlNet（骨骼+深度+线稿），实现更精细的控制

→ InstantID / IP-Adapter：用一张照片驱动AI生成，保持人物面部高度相似，商业写真神器

→ ControlNet + LoRA组合：LoRA控制风格，ControlNet控制构图和姿态，我在做品牌系列插画时用过，效果很好

→ Tile分块重绘：只重绘图片的一部分而不影响其他区域，电商主图优化神器
