# 第一次用ComfyUI做视频？先图生视频，别一上来就文生视频

前两周有个做女装的朋友找我，说想给新款连衣裙拍个15秒短视频挂详情页。她问：能不能让电脑直接"想象"一个模特穿上裙子走两步？我说能，但你别一上来就文生视频。

为什么？因为她要的是"这条裙子、这个颜色、这个版型"，不是AI自由发挥的一团模糊布料。我后来用ComfyUI给她搭了个图生视频工作流：先出一张定妆照，再让视频模型在这张图上"动起来"。出来的视频，裙子版型没跑偏，质感也对。她看完说了一句：这才是我要的。

## 一个类比先讲清：文生视频 vs 图生视频

文生视频，就像让一个没看过剧本的导演直接开机。你扔一句话过去："一个女孩在街上走"，他拍出来可能是任何女孩、任何街、任何走法。自由是自由，但不可控。

图生视频，相当于你先递给他一张定妆照+分镜。他照着演，人物、服装、场景都锁死了，只是"动"起来。稳定，是做商业内容最值钱的东西。

说人话：文生视频是"凭空编"，图生视频是"照着演"。新手想出可控的片，图生视频是更稳的入场姿势。

## 为什么这事儿现在值得学？

我去年试过剪映的图文成片，效果……不提了，人物脸都糊成马赛克。后来手里有ComfyUI，才发现视频生成已经到了"能干活"的临界点。

视频是内容创作的下一战场。电商产品短片、小红书种草视频、广告分镜预演——这些以前要么请拍摄团队，要么自己熬夜剪。现在一套节点图，半小时出一个能用的版本。省下的不是时间，是**试错成本**。以前拍废一条片子，钱和资源都沉没了；现在跑废一条，改个参数重来。

## 怎么上手？四步跑通第一个视频工作流

### 第1步：先看你显卡的饭碗

视频模型吃显存，这是第一道坎。我自己的卡是 [填入你的显卡型号/显存，建议≥12GB]，刚开始直接上 HunyuanVideo 原版，跑一半直接黑屏——爆显存了。踩的坑我记下来：显存紧，就别碰原版大模型。

- 显存 ≥16GB：Wan2.1 / Seedance 这类主流模型能跑
- 显存 8-12GB：用 GGUF 量化版，或选 LTX-Video 这种轻量模型
- 显存 <8GB：先别硬刚视频，从生图打基础

### 第2步：装对节点包

ComfyUI Manager 里搜两个就够起步：
- `ComfyUI-VideoHelperSuite`（负责把帧序列合成视频）
- 你选的模型对应的节点包（比如 Wan 的 `ComfyUI-WanVideoWrapper`）

我踩过第二个坑：节点包装了但版本不对，加载模型时直接报错 "missing key"。后来去 GitHub 拉了最新版才解决。装完记得重启 ComfyUI。

### 第3步：搭图生视频链路

核心节点连起来就这一条线：

```
加载图片 → VAEEncode(编码首帧) → 视频采样器 → VAEDecode(解码) → VideoCombine(存成mp4)
```

关键：把"固定部分"和"变量部分"分开。模型、VAE、采样步数固定不动；图片输入、运动强度、帧数单独拎出来，方便你换素材反复跑。

### 第4步：调三个最关键的参数

- **帧数（frames）**：起步 16-24 帧。别贪多，帧数翻倍，显存和时长都翻倍。
- **帧率（fps）**：8-12 足够看。电商展示 8fps 就顺了。
- **运动强度**：值越大动作越夸张。我一般先从 0.6 试，太大人物会"抽搐"。

## 常见误区

**误区1：帧数拉满才像电影**
错。我第一次设了 81 帧，结果渲了 40 分钟还没出。短视频 16-24 帧足够，电影感靠构图和运镜，不靠帧数堆。正确做法：先用最小帧数跑通，确认效果再加。

**误区2：文生视频一定能出好片**
也错。纯文本太自由，人物、物体经常中途变形（业内叫"闪烁/形变"）。正确做法：要可控内容，先出定妆照，用图生视频锁死主体。

**误区3：直接上原版大模型**
显存不够必崩。正确做法：卡不够，上量化版（GGUF）或开 Tiled VAE 分块解码，硬刚只会黑屏。

## 进阶方向

跑通基础版后，可以往上加料：
- **首尾帧控制**：给定第一帧和最后一帧，让中间自动补全，运镜更可控
- **运动笔刷**：只让画面某块动（比如裙摆飘，背景静），省显存又自然
- **视频超分**：低帧视频用放大模型补到 4K，发抖音够清晰
