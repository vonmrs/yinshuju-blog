# AI生图：让你的角色"长得一样"，场景"说建就建"

<!-- 配图提示词：一个画板上有多个相同人物的不同姿态画作，风格统一，旁边有一只手握着AI绘图笔，赛博朋克风格，紫色调 -->

昨天发了AI短剧全流程概览，有个读者留言问得特别实在："你说的我都懂，但角色一致性怎么解决？每张图AI画出来的人长得都不一样，怎么拼成一条连续的短剧？"

问得好。

这正是AI短剧最核心的难点——不是"能不能画出来"，而是"能不能画得一样"。

今天先把这个硬骨头啃掉。

## 什么是AI生图中的"角色一致性"？

先说清楚问题。

用Midjourney或者普通Stable Diffusion跑过图的人应该有体会：同一套提示词，跑两次，人物长相可能完全不一样。同一个"穿红裙子的女人"，第一张是东方面孔，第二张变成欧美脸，第三张连发型都换了。

这对海报设计、插画创作无所谓。但对短剧来说是致命的——观众看到第三个镜头主角换了一张脸，直接出戏。

**角色一致性**，就是让AI在不同场景、不同动作、不同光线下，画出"同一个人"。

类比一下：就像传统影视里的"定妆照"——演员确定造型后，所有镜头都参照同一套视觉标准。AI短剧里的"定妆照"，就是你的角色参考图（Reference）。

## 为什么角色一致性是最难的一关？

我踩过的坑：第一次跑AI短剧，我信心满满地画了10个分镜，结果放一起看，6个人长得都不一样——女主角在镜头1是黑色短发，到镜头5变成棕色卷发，男主角更离谱，镜头2和镜头8的脸型完全是两个人。

后来我才明白：**AI生图的本质是"生成"，不是"复制"**。它每次都在重新"想象"一张图，所以天然不稳定。

解决方案分三层，我按难度从低到高说：

## 第一层：Reference Image（参考图）——门槛最低，效果够用

原理很简单：给AI一张"标准照"，让它照着画。

在ComfyUI里，用"Reference"节点或者Load Image节点，把角色定妆照传进去，再用文字描述动作和场景。AI会尽量保留原图中的人物特征，同时生成新的动作和背景。

**我的实测效果**：
- 五官特征保留率：约70-80%
- 发型/服装变化：偶尔发生
- 适用场景：近景和中景镜头

这层方案适合：刚起步、预算有限、角色数量少（1-2个）的短剧项目。

## 第二层：IP-Adapter（中文名：图生图适配器）——中等难度，效果明显提升

IP-Adapter是Stable Diffusion的一个扩展，最早在2024年初的ComfyUI里引入。它的原理比Reference更聪明——不是简单"参考"，而是把参考图的特征编码成向量，注入到生图过程中。

**为什么比Reference好？**

打个比方：Reference像是"照着照片描"，IP-Adapter像是"记住照片里这个人的特征，然后凭记忆画"。后者对特征的提取更深入，生成结果更稳定。

**我的踩坑记录**：IP-Adapter有多个版本（SD1.5/SDXL/SD3），用错了版本会报错或者效果极差。我用的是SDXL版本的IP-Adapter Plus（推荐），配合Flux模型使用，兼容性最好。

节点串联方式（简化版）：
```
Load Image（角色定妆照）→ IP-Adapter（加载模型）→ KSampler（采样生成）
```

## 第三层：LoRA训练——高难度，效果最稳定

LoRA（Low-Rank Adaptation）是什么？我之前的文章里打过比方：给AI换一件衣服。

更准确地说：LoRA是针对特定人物或风格训练的小型权重文件。它不是让AI"参考"一张图，而是让AI真正"认识"这个人——就像你认识一个朋友，看一眼背影就知道是谁。

**训练流程**：
1. 收集素材：目标人物的不同角度、不同表情、不同服装的图片，10-30张（越多越好，但要注意质量：高清、正脸、光线清晰）
2. 打标（Tagging）：给每张图加上描述性标签，比如"woman, short black hair, serious expression"
3. 训练：用ComfyUI的LoRA训练节点，跑10-30分钟（取决于显卡性能）
4. 使用：加载训练好的LoRA文件，用简单提示词就能生成"同一个人"的不同场景

**我踩过的坑**：
- 训练素材不够多样化——只用了10张正脸照，结果生成侧脸时人物完全变形。后来补充了不同角度的照片才改善。
- 打标不准确——有些工具的自动打标会把"眼镜"识别成"装饰品"，导致生成的角色有时戴眼镜有时不戴。解决方法是手动修正打标文件。

## 三层方案怎么选？

| 方案 | 难度 | 成本 | 效果 | 适合场景 |
|------|------|------|------|----------|
| Reference | ⭐ | 免费 | 70-80%一致 | 刚起步、单角色、预算0 |
| IP-Adapter | ⭐⭐ | 免费（需显卡） | 80-90%一致 | 3个角色以内、有ComfyUI基础 |
| LoRA | ⭐⭐⭐ | 训练需时间成本 | 90-95%一致 | 多角色、高质量要求、商业项目 |

**我的折中建议**：先从Reference起步，把流程跑通；等项目需要做3个以上角色时，上IP-Adapter；等你有耐心打磨细节时，试一下LoRA。

不要一开始就想用LoRA——训练一个高质量LoRA可能要反复调参数，新手很容易在这里卡住，一卡就是两三天，热情全没了。

## 场景图怎么画？

说完角色，场景同样重要。

AI短剧的场景通常分两类：**实景类**（咖啡馆、办公室、街道）和**虚构类**（太空站、魔法世界、未来都市）。

实景类相对简单——可以用真人照片打底，用ControlNet控制构图，AI负责"美化"和"风格化"。

虚构类是真正考验功力的地方——你需要描述清楚空间结构、光线氛围、色调风格。提示词模板：

```
[场景类型], [时间段/光线], [色调], [情绪], [细节描述]
示例：
废弃工厂, 黄昏时分, 暖橙色逆光, 压抑紧张, 散落的工作台,
生锈的机械, 灰尘漂浮, 烟雾缭绕
```

**我自己的实操经验**：场景提示词里"情绪"和"色调"是最重要的两个维度，AI对这两项的理解最准确。具体的物件描述反而容易出错——你说"一张木桌"，AI可能给你画一张现代极简桌，所以物件描述要笼统一点，"旧木工作台"比"一张木桌"效果好很多。

## 常见误区

**误区1：角色LoRA越训练越好**

LoRA质量的关键是"素材质量"，不是数量。30张高清多样图，比100张模糊同角度图效果好得多。

**误区2：人物一致=画面完全一样**

错。一致是"能认出是同一个人"，不是"每张图完全一样"。允许角度、表情、光影有变化，只要五官特征和整体气质统一就行。

**误区3：场景图用真实摄影素材更省事**

有时候确实更省事。但AI场景的优势在于：**它能画出真实摄影做不到的画面**——比如"赛博朋克风格的唐朝长安城"，或者"火星上的江南水乡"。如果你的剧本需要独特视觉风格，AI场景图是真正的差异化竞争力。

## 进阶方向

当你角色一致性问题解决后，可以研究这些方向：

1. **光影一致性**：同一场戏，不同镜头之间的光线方向、色温要统一。用"色彩校正"节点统一色调。
2. **镜头景别**：学会用AI画出特写、中景、远景、全景，统一景别变化让短剧更有电影感。
3. **动态模糊和景深**：真实影视有虚化和运动模糊，AI生图也可以模拟——用ControlNet的深度图节点控制虚化区域。
4. **批量化工作流**：把角色LoRA + IP-Adapter + ControlNet打包成一个工作流，一键生成同一角色的多个场景，大幅提升效率。
