# 开源数字人本地部署：我在Mac上跑通了Duix.Avatar

**棱镜 · AI数字人系列 · 第5天**

---

前两天有个读者问我："这些数字人工具都要花钱吧？有没有免费的？"

我说有，但得自己动手。他犹豫了一下："是不是很复杂？需要写代码吗？"

确实要写几行命令，但没那么吓人。今天把两个开源方案都跑一遍——硅基智能的Duix.Avatar和AIGCPanel，告诉你本地部署的真实门槛在哪里。

## 为什么选这两个

七月这波开源潮里，这两个方案最值得关注：

**Duix.Avatar** —— 硅基智能开源，10秒视频克隆形象+声音，支持本地推理。核心卖点是"一站式"：上传视频→生成数字人，不需要自己拼接口型驱动模型。

**AIGCPanel** —— 开源数字人系统，把MuseTalk、LatentSync、Wav2Lip三个口型模型和CosyVoice、GPT-SoVITS两个声音克隆模型都集成进去了。适合想自己定制工作流的玩家。

我自己的选择逻辑：如果你只是想快速生成数字人视频，Duix.Avatar更省心；如果你想深入理解整个流程、甚至二次开发，AIGCPanel更灵活。

## Duix.Avatar部署实战

### 前置条件

- Python 3.8以上
- 显卡：推理4G显存够用，训练建议8G以上（Mac M系列芯片也能跑，用MPS加速）
- 硬盘：至少20G空间（模型文件大）

### 步骤1：克隆仓库

```bash
git clone https://github.com/siliconflow/Duix.Avatar.git
cd Duix.Avatar
```

### 步骤2：创建虚拟环境

```bash
python3 -m venv venv
source venv/bin/activate  # Mac/Linux
# venv\Scripts\activate  # Windows
```

### 步骤3：安装依赖

```bash
pip install -r requirements.txt
```

这一步我踩了坑：requirements.txt里的torch版本跟我的CUDA版本不匹配，报错"RuntimeError: CUDA out of memory"。解决方案是先单独安装正确版本的PyTorch：

```bash
# 去pytorch.org根据你的CUDA版本选择安装命令
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
```

### 步骤4：下载模型

项目Release页面有预训练模型，约15GB。下载后放到`checkpoints/`目录。

### 步骤5：运行推理

```bash
python inference.py --video your_video.mp4 --audio your_audio.wav --output output.mp4
```

第一次运行会慢一些，因为要加载模型到显存。处理一段30秒的视频，我的RTX 3060用了约2分钟。

## AIGCPanel部署实战

### 前置条件

- Python 3.10（注意版本要求更严格）
- 显卡：8G以上推荐（因为集成多个模型）
- Docker（可选，用于容器化部署）

### 步骤1：克隆仓库

```bash
git clone https://github.com/AIGCPanel/AIGCPanel.git
cd AIGCPanel
```

### 步骤2：安装依赖

```bash
pip install -r requirements.txt
```

### 步骤3：下载模型

AIGCPanel集成了多个模型，需要分别下载：
- 口型驱动模型：MuseTalk、LatentSync、Wav2Lip
- 声音克隆模型：CosyVoice、GPT-SoVITS

项目提供了下载脚本：

```bash
python download_models.py
```

这一步要下载约50GB模型文件，建议用代理或晚上挂着下载。

### 步骤4：启动Web界面

```bash
python app.py
```

浏览器打开`http://localhost:7860`就能看到Web界面，类似Stable Diffusion WebUI的风格。

## 我的真实踩坑记录

**坑1：Python版本冲突**

Duix.Avatar支持Python 3.8，AIGCPanel要求3.10。我用Conda创建了两个独立环境：

```bash
conda create -n duix python=3.8
conda create -n aigcpanel python=3.10
```

**坑2：显存不够用**

AIGCPanel同时加载多个模型，8G显存跑LatentSync会爆。解决方案：在配置文件里把默认口型模型改成Wav2Lip或MuseTalk。

**坑3：音频格式不兼容**

两个项目都要求WAV格式，采样率16000Hz。我用的MP3转换后报错，后来用FFmpeg预处理：

```bash
ffmpeg -i input.mp3 -ar 16000 -ac 1 output.wav
```

## 性能对比

| 维度 | Duix.Avatar | AIGCPanel |
|---|---|---|
| 部署难度 | 中（单模型链路） | 高（多模型集成） |
| 显卡要求 | 4G推理 | 8G推荐 |
| 硬盘占用 | 约15GB | 约50GB |
| 灵活性 | 固定流程 | 可自定义模型组合 |
| Web界面 | 无（命令行） | 有 |
| 最佳场景 | 快速生成 | 定制开发 |

## 适合谁用

**Duix.Avatar适合**：
- 有一定命令行基础
- 只需要生成数字人视频，不打算二次开发
- 硬件资源有限（4G显存也能跑）

**AIGCPanel适合**：
- 想深入研究数字人技术栈
- 需要定制工作流（比如换用不同的口型模型）
- 有较强的调试能力和硬件资源

我自己的路径是：先用Duix.Avatar跑通流程，理解整个Pipeline，再用AIGCPanel做实验和定制。两个方案都跑一遍，你对数字人的理解会上一个台阶。
